    Règles du jeu

    Cinq règles, pour tous les skills

    Rien ne part sans vous

    Les skills préparent. Vous relisez, vous validez, vous publiez.

    Vos clés restent chez vous

    Chaque clé d'API est personnelle, rangée dans votre fichier cles-api.env, jamais partagée.

    procivis.fr, dans vos droits

    Le back-office se pilote avec votre compte. Couleurs, logos et favicon restent à l'équipe nationale.

    L'Agora se lit, ne s'écrit pas

    Un skill peut reprendre une actualité de l'Agora pour vos canaux. Il n'y publie jamais.

    Prudence avec les données

    Pas de données personnelles de clients ou de collaborateurs dans un assistant que votre société n'a pas validé.

    Un skill vous manque ?

    L'équipe communication nationale tient cette bibliothèque. Dites-nous ce qui vous manque, ce qui marche et ce qui coince.
